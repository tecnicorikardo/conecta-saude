Agora quero que você trabalhe na concepção visual e experiência de usuário (UI/UX) do projeto de Comunicação Institucional Hospitalar definido anteriormente.

Neste momento, o foco principal NÃO é criar novas funcionalidades.

O objetivo é definir e apresentar como o sistema deverá ser visualmente, criando exemplos concretos de layout, telas, componentes, cores, navegação e estilo.

O sistema deve transmitir visualmente:

Confiança

28. REGRAS DE DESIGN

Não copiar diretamente:

WhatsApp;
Telegram;
Messenger;
Slack.

Pode utilizar conceitos conhecidos de UX, mas a identidade visual deve ser própria.

Evitar:

excesso de verde;
excesso de azul hospitalar;
interface infantil;
excesso de emojis;
excesso de sombras;
excesso de bordas;
excesso de animações;
visual de rede social.

Priorizar:

limpeza + profissionalismo + segurança + simplicidade.

29. PRIMEIRO PASSO

Antes de começar a implementar todas as telas, faça uma proposta visual inicial.

Apresente:

OPÇÃO A

Estilo institucional moderno.

OPÇÃO B

Estilo tecnológico e sofisticado.

OPÇÃO C

Estilo hospitalar minimalista.

Para cada opção apresentar:

paleta;
tipografia;
estilo dos cards;
estilo dos botões;
aparência do menu;
aparência do chat;
aparência dos comunicados.

Depois escolha a opção que considerar mais adequada para um hospital público/institucional e justifique brevemente a escolha.

Somente depois dessa definição avance para a implementação visual.

30. PRINCÍPIO FINAL

O usuário deve abrir o sistema e imediatamente perceber:

"Isso é uma ferramenta oficial de trabalho."

A interface deve transmitir:

Profissionalismo.
Organização.
Segurança.
Confiança.
Comunicação institucional.

O resultado deve ser moderno o suficiente para parecer uma plataforma atual, mas sóbrio o suficiente para ser apresentado à direção de um hospital.
